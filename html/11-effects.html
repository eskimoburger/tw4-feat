Shadows, masks & effects

Box, text and drop shadows, rings, gradient and image masks, filters, blend modes, native color schemes and focus outlines, including the v4 renames that changed them. Every demo below is live Tailwind v4.3.3.

Box-shadow scale

v4.0

v4 gives every step of the shadow scale a name and adds shadow-2xs, so it now runs 2xs, xs, sm, md, lg, xl, 2xl. Names moved down one notch from v3: the old shadow-sm is shadow-xs and the old bare shadow is shadow-sm. Use small shadows for inputs and cards, large ones for menus and modals.

Shadow opacity modifier

v4.1

Add an opacity modifier to a shadow size to change how dark the default shadow is without touching its color: shadow-xl/20. The same modifier works on inset-shadow-*, drop-shadow-* and text-shadow-*. Built-in shadows are only 5 to 25 percent black, so /40 or /60 is a big step up.

  • shadow-xl/20
  • shadow-lg/50
  • inset-shadow-sm/50
  • drop-shadow-xl/25
  • text-shadow-lg/50
  • shadow-xl/[35%]
  • shadow-xl/(--o)

Rings

v4.0

A ring is a solid, spread-only box-shadow that never changes layout. In v4 bare ring is 1px of currentColor (v3 was 3px blue), so the old look is now ring-3 ring-blue-500. Ring colors take opacity modifiers, and ring-offset-* still opens a gap.

Inset shadows

v4.0

A second shadow layer drawn inside the box, independent of shadow-*. Sizes are inset-shadow-2xs, xs and sm, with colors and (from 4.1) an opacity modifier. Use it for pressed buttons, recessed fields and a one-pixel top highlight.

Inset rings

v4.0

A ring drawn inside the border box as its own layer. It defaults to 1px of currentColor like ring, takes colors and opacity, and never changes layout. It is the cleaner choice for badges and fields, and it brings back a card edge in dark mode where outer rings fade.

Layered shadows and rings

v4.0

v4 builds box-shadow from four independent layers, each with its own size and color, so up to four effects stack on one element without overriding each other. Painted top to bottom the order is inset shadow, inset ring, ring, then shadow. To remove one layer use shadow-none, inset-shadow-none, ring-0 or inset-ring-0.

  • shadow-lg shadow-indigo-500/40
  • ring-1 ring-indigo-700
  • inset-shadow-2xs inset-shadow-white/40
  • inset-ring inset-ring-white/10
  • shadow-[6px_6px_12px_#bebebe,-6px_-6px_12px_#fff]
  • peer-checked/a:shadow-xl

Drop shadows

v4.1

drop-shadow-* uses filter: drop-shadow(), so the shadow follows the real shape of an SVG, a clipped element or a speech-bubble tail. v4.0 renamed the scale (xs to 2xl); 4.1 added colors and the opacity modifier. For a plain rectangle, shadow-* is cheaper.

outline-hidden vs outline-none

v4.0

In v3, outline-none drew an invisible outline that still showed in forced-colors mode. v4 renames that behavior to outline-hidden and makes outline-none really set outline-style: none. Use outline-hidden when you add your own focus indicator. Bare outline is now 1px, and outline-2 already implies a solid style.

Backdrop filters and glass

v4.0

Edge masks

v4.1

New in 4.1: fade one edge (mask-b-from-50%), two opposite edges (mask-x-from-70%) or any combination. The letter names the edge that fades, from is where the fade starts and to where it ends. Use masks instead of overlay gradients so nothing has to match the page background in light and dark.

  • mask-t-from-50%
  • mask-r-from-30%
  • mask-b-from-20% mask-b-to-80%
  • mask-l-from-50%
  • mask-x-from-70% mask-x-to-90%
  • mask-y-from-[calc(100%-2rem)]
  • mask-t-from-20
  • mask-b-to-transparent
  • mask-none

Docs: masking edges

Tailwind emits the unprefixed mask-image, which needs Chrome 120+, Safari 15.4+ or Firefox 53+. A mask also clips the element's own shadow and ring, so put those on a wrapper.

Angled linear masks

v4.1

mask-linear-50 sets the gradient angle (use -mask-linear-50 for a negative angle), and mask-linear-from-* and mask-linear-to-* set the opaque and transparent stops. Stops accept percentages, spacing numbers, colors, (--var) and arbitrary values, so a CSS variable can drive them.

  • mask-linear-from-60%

Radial masks

v4.1

mask-radial-from-* and mask-radial-to-* set the stops, mask-radial-at-* sets the center, mask-radial-closest-side and friends set the size, and mask-circle or mask-ellipse set the shape. Defaults are an ellipse, farthest-corner, centered. Good for vignettes, spotlights and soft glows.

Conic masks

v4.1

mask-conic-from-75% mask-conic-to-75% makes a hard wedge starting at 12 o'clock and running clockwise, which is a progress ring. mask-conic-90 rotates the start angle (negative with -mask-conic-90). Soft stops give comet tails, radar sweeps and gauges.

Combining masks

v4.1

The edge, linear, radial and conic mask utilities are separate layers that Tailwind intersects, so stacking them multiplies the shapes. mask-add, mask-subtract, mask-intersect and mask-exclude choose the boolean operation, mainly for arbitrary multi-layer masks.

  • mask-b-from-50% mask-radial-from-80%
  • mask-x-from-80% mask-y-from-80%
  • mask-add
  • mask-subtract
  • mask-intersect
  • mask-exclude
  • mask-[radial-gradient(…),radial-gradient(…)]

Docs: mask-composite

A raw mask-[...] value and the gradient utilities both write mask-image, so they replace each other. To combine them, nest one masked element inside another.

Image masks

v4.1

Use any image as a mask: mask-[url(...)] for a literal, mask-(--my-mask) for a variable and mask-none to clear it. An SVG shape works as a recolorable icon, because the color is just a normal bg-* utility. mask-alpha, mask-luminance and mask-match pick how the mask is read.

  • mask-[url(/img/star.svg)]
  • mask-(--mask-star)
  • mask-none
  • mask-alpha
  • mask-luminance
  • mask-match
  • mask-type-alpha
  • mask-type-luminance
  • mask-contain mask-center mask-no-repeat

Docs: image mask

This page has no external images, so the masks are inline SVG data: URIs stored in theme variables. Typing a long URI inside mask-[url(...)] is fragile (spaces become underscores, # must be %23), so a variable is easier.

They matter once your mask is a small tile or a shape rather than a full-size gradient.

Element blending

core

mix-blend-* blends an element, and everything inside it, with whatever is painted behind it in the same stacking context. Use isolate on the parent so only the elements you want mix, and not the page background.

  • mix-blend-normal
  • mix-blend-multiply
  • mix-blend-screen
  • mix-blend-overlay
  • mix-blend-difference
  • mix-blend-soft-light
  • mix-blend-plus-lighter
  • isolate

Docs: mix-blend-mode

There are 18 modes in total (the 16 standard ones plus plus-darker and plus-lighter). The two plus-* modes have patchier browser support.

Background blending

core

bg-blend-* blends an element's own background layers, such as a gradient image over its background color, so you can tint or darken artwork without an extra overlay element. It needs both a color and an image on the same element. For blending with other elements use mix-blend-*.

  • bg-blend-normal
  • bg-blend-multiply

  • bg-blend-overlay

color-scheme

v4.0

scheme-light, scheme-dark and scheme-light-dark set color-scheme, which tells the browser how to draw native UI: form controls, date pickers, select menus, scrollbars and system colors. It does not change your Tailwind colors. Set it on html or on any container.

  • scheme-normal
  • scheme-light
  • scheme-dark
  • scheme-light-dark
  • scheme-only-light
  • scheme-only-dark
  • scheme-light dark:scheme-dark
  • bg-[Field] text-[FieldText]
  • accent-indigo-500

Docs: color-scheme

Preflight makes form controls transparent, so to let the control background follow the scheme use the system colors bg-[Field] and text-[FieldText], as the docs do. Custom scrollbar colors arrive with the v4.3 scrollbar-* utilities, covered on page 14.

Effect tokens in @theme

v4.0

Every effect has a theme namespace, and declaring a variable in @theme creates the utility. --shadow-soft becomes shadow-soft, --drop-shadow-glow becomes drop-shadow-glow, and so on. Reset a namespace with --shadow-*: initial to replace the defaults.

  • --inset-shadow-*
  • --drop-shadow-*
  • --text-shadow-*
  • --blur-*
  • --color-brand

Animating effects

v4.1

What animates and what snaps. transition eases box-shadow and filter. Tailwind's mask stop variables are registered with the syntax *, so they jump instead of transitioning, while gradient from-* and to-* stops glide. To animate a mask, keyframe mask-position or register your own typed @property.

  • transition-shadow
  • hover:shadow-xl
  • animate-shimmer
  • transition-[--fade]
  • hover:[--fade:0%]
  • motion-safe:hover:-translate-y-1
  • motion-reduce:animate-none
  • @property --fade

Docs: mask-image · animation
